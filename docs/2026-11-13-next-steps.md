## 다른 컴퓨터에서 시작하기

```bash
git clone https://github.com/shway81-droid/ttalkkak-bogyul.git
cd ttalkkak-bogyul
npm install
npx playwright install chromium
npm run serve     # http://localhost:4173
npm test          # 단위 검사 + 자료 검증 + 글꼴 검사
npm run e2e       # 브라우저 검사(약 7분)
```

- 짬짬이 자료를 다시 가져오려면 `npm run import` (처음에는 `.cache/jjam-classroom` 에 짬짬이 저장소를 받습니다). 이미 받은 사본 그대로 쓰려면 `node scripts/import-jjam.mjs --no-pull`.
- 화면 파일을 더하거나 빼거나 바꾸면 `npm run stamp` (서비스 워커 파일 목록·캐시 이름).
- 인물 사진은 세로 540px·화질 70 WebP 로 줄여 둔다(2026-11-14, 7.3MB → 3.4MB). `npm run import` 가 복사하며 줄이고, 따로 줄이려면 `npm run photos`(이미 작은 사진은 건드리지 않음).

## 미뤄 둔 작은 문제 (검토에서 나옴)

1. **사진 출처 줄이 잘림** — 1280×720 처럼 좁은 화면에서 가장 긴 출처 줄(약 79자)은 끝이 잘려 라이선스 이름이 가려지고, 출처 줄이 나타날 때 사진이 약 24px 줄어듦. 라이선스를 앞에 두거나 두 줄을 허용하고, 묻는 동안에도 빈 줄 자리를 잡아 두면 해결. (`js/activities/word.js`, `css/app.css` 의 `.person-credit`)
2. **업데이트 때 사진까지 다시 받음** — 화면 파일 하나만 바뀌어도 캐시 이름이 바뀌어, 이미 열어 본 PC가 사진까지 약 9MB를 다시 받음. `addAll` 은 전부 아니면 전무라 불안정한 와이파이에서는 오프라인 사본이 안 생길 수 있음. 사진만 따로(사진 해시로 이름 지은) 캐시에 두면 해결. (`sw.js`, `scripts/sw-version.mjs`)
3. **가져오기 도중 실패** — 사진 폴더를 지운 뒤 복사하므로 도중에 실패하면 폴더가 반만 차고 `people.json` 은 옛것으로 남음. 경로를 먼저 모두 확인하고 임시 폴더에 복사한 뒤 바꿔 넣으면 해결. 원본 주소가 위키미디어인지·사진 중복 검사도 없음. (`scripts/import-jjam.mjs`, `scripts/validate-data.mjs`)
4. **사진이 안 읽히면 빈 칸** — 짬짬이처럼 이미지 오류 때 힌트를 저절로 열면 해결(미리 담아 두므로 드묾).
5. **그리기 흔적** — 규칙 화면의 준비물(prep) 표시 코드는 이제 쓰는 곳이 없음(`js/ui/runner.js`, `.rules-prep`). 인사 규칙·대본의 "끝까지 함께하면 ★"은 그리기 별 규칙에서 온 말로, 지금은 이야기의 [모두 ★]만 받쳐 줌 — 문구를 뺄지 정하기.
6. **브라우저 검사 한 번 멈춤** — 전체 e2e 3번 가운데 1번, 말놀이 검사의 첫 화면(학년 버튼)이 30초 안에 뜨지 않음. 첫 화면 40번 열기·다시 돌린 전체 검사에서는 재현되지 않아 원인 모름. 다시 나오면 그때의 콘솔·네트워크 기록부터 볼 것.
7. 이전 검토에서 미룬 것: 되돌리기가 뒤의 [다음 모둠에게]까지 차례를 되돌림, 지금 순서 알약을 다시 누르면 순서가 처음부터 다시 시작, 동작 줄이기 설정에서 [다음 순서] 깜빡임 없음, ⏸ 중 [맞혔어요] 뒤 정답 화면이 멈춘 채, 반 인원 칸을 비우면 2명, 이야기 힌트·예시 두 번 누르면 다시 닫힘, 끝에 / 없는 주소는 오프라인에서 안 열림, e2e 에 [다음 순서] 두 번 누름 검사가 없음, 자료 검증이 문항 자체(보기 중복·빈 정답)는 보지 않음.
