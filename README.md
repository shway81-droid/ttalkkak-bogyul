# 딸깍 보결

갑자기 보결 들어간 초등 선생님이 **학년만 누르면** 40분 모둠 수업이 진행되는 사이트입니다.
교실 TV에 연결된 컴퓨터와 마우스만 있으면 됩니다. 설치·로그인이 없고, 한 번 열면 인터넷이 끊겨도 동작합니다.

## 쓰는 법

1. 링크를 엽니다.
2. 학년(1~6)을 고릅니다. 흐름(신나게 열기 / 차분하게 열기)과 모둠 수(3~8)는 그대로 두어도 됩니다.
3. **[시작]** 을 누릅니다. 인사는 바로 시작하고, 다른 순서는 규칙 안내가 먼저 나오니 읽어 주고 [시작]을 누르면 됩니다.
4. 시간이 다 되면 위쪽 **[다음 순서]** 가 천천히 빛납니다. 넘어가는 것은 선생님이 정합니다.

40분은 인사 → 인물 퀴즈 → 몸으로 말해요(또는 상식 퀴즈) → 말놀이 → 이야기 나누기 → 별 축하 순서입니다(차분하게 열기는 이야기가 먼저). 종이·연필 같은 준비물은 필요 없습니다.
모둠 별은 다 함께 모아 "우리 반 별"로 축하합니다. 모둠 순위는 보여 주지 않습니다.
위쪽 별판에 **우리 반 별 목표**(모둠 수 × 6개)가 막대로 차오르고, 채우면 꽃가루와 함께 축하합니다.

- **선생님용 정답 창:** 첫 화면 아래 [선생님용 정답 창 열기] 또는 수업 중 위쪽 눈 모양 단추를 누르면 새 창이 열리고, 지금 화면에 나온 문제의 정답(인물 퀴즈는 사진과 이름, 이야기는 선생님 안내)이 바로 뜹니다. TV는 '확장' 화면으로 두고 이 창은 노트북 화면에 두세요('복제' 화면이면 아이들에게도 보입니다).
- **진행 대본:** 학년을 고른 뒤 첫 화면 아래 [… 선생님용 진행 대본 인쇄]를 누르면 그 학년의 A4 한 장 대본이 열립니다. 화면을 못 쓰는 교실에서도 말과 칠판만으로 진행할 수 있습니다.
- **조작:** Space 잠깐 멈춤, → 다음 순서. 위쪽 단추로 소리 끄기·정답 창·전체화면·끝내기.
- **몸으로 말해요:** 한 모둠이 1분 동안 낱말을 이어서 맞힙니다. 맞힐 때마다 ★, 어려우면 [넘기기]로 다음 낱말, 1분이 지나거나 [차례 끝]이면 다음 모둠.

## 파일 하나로 나눠 주기

`npm run single` 을 돌리면 `dist/딸깍보결.html` 파일 하나(약 6MB)가 만들어집니다.
이 파일만 메신저·메일·USB로 주고받아 **더블클릭**하면 인터넷 없이도 수업·선생님용 정답 창·진행 대본·사진 출처가 모두 됩니다(크롬·엣지 권장).
웹사이트와 같은 코드·자료로 만드므로, 웹사이트를 고친 뒤 다시 돌리면 최신 파일이 나옵니다.

## 개발

정적 사이트입니다(빌드 단계 없음, 실행 중 외부 라이브러리 없음). Node 24 이상.

```bash
npm install                       # 검사용 Playwright
npx playwright install chromium   # 처음 한 번
npm run serve                     # http://localhost:4173
npm test                          # 단위 검사 + 자료 검증 + 글꼴 글자 검사
npm run e2e                       # 브라우저 검사(12세트, 작은 화면, 진행 대본, 오프라인)
npm run import                    # 짬짬이 자료 다시 가져오기(data/*.json, 인물 사진 assets/people/)
npm run stamp                     # 화면 파일·사진을 바꾼 뒤 sw.js 파일 목록·캐시 이름 새로 찍기
npm run single                    # 단일 HTML 파일 만들기(dist/딸깍보결.html)
npm run photos                    # 인물 사진을 세로 540px 로 줄이기(이미 작은 것은 그대로)
```

- 화면 파일(`js/`·`css/`·`data/`·`assets/`·html 등)을 **더하거나 빼거나 바꾼 뒤에는 `npm run stamp`** 로 `sw.js` 의 파일 목록(`ASSETS`·`PHOTOS`)과 캐시 이름을 새로 찍습니다. 그래야 인터넷이 끊겨도 모든 화면이 열리고, 배포 뒤 브라우저가 옛 파일 대신 새 파일을 한꺼번에 받습니다(`npm test` 가 잊으면 알려 줍니다).
- 인물 사진은 화면 파일과 다른 캐시에 담습니다. 화면 파일만 바뀐 배포에서는 이미 열어 본 PC가 사진을 다시 받지 않고, 사진을 몇 장 못 받아도 오프라인 사본은 만들어집니다(빠진 사진은 다음에 열 때 마저 받음).
- `npm run import` 는 새 자료를 임시 폴더(`.cache/import-stage`)에 만들고 자료 검증을 통과해야 `data/`·`assets/people/` 을 바꿉니다. 도중에 실패하면 지금 자료는 그대로입니다.
- 주소는 끝에 `/` 를 붙여 즐겨찾기해 주세요(`…/ttalkkak-bogyul/`). 끝에 `/` 가 없는 주소는 서비스 워커 범위 밖이라 인터넷이 끊기면 열리지 않습니다.
- 자료를 바꾸면 `node scripts/validate-data.mjs` 로 세트마다 후보가 충분한지 확인합니다.
